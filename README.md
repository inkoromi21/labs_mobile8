# Задание

Лабораторная работа 8. Изучить корутины, сетевые запросы, Retrofit и внедрение зависимостей. Доработать Race Tracker и Mars Photos, создать приложение с персонажами Rick and Morty.

# Выполнено

Созданы три модуля: racetracker, marsphotos и rickandmorty. В Race Tracker два участника бегут одновременно; гонку можно приостановить, продолжить и сбросить. Прогресс сохраняется при повороте экрана. В Mars Photos фотографии загружаются через Retrofit и отображаются сеткой с помощью Coil. Добавлены репозиторий, контейнер зависимостей, состояния загрузки и ошибки, повторный запрос.

В Rick and Morty список персонажей подгружается страницами при прокрутке. Отдельный экран показывает сведения о персонаже и эпизоды с его участием. У каждого экрана свои ViewModel и состояние. Для доступа к API используются корутины, Retrofit, репозиторий и внедрение зависимостей через конструктор. Написаны модульные тесты и проверки интерфейса.

Для запуска выберите нужный модуль в Android Studio. Сетевым приложениям требуется интернет.
